Finally, it should be noted that this script will NOT automatically determine your system architecture, utilising only the amd64 packages for a 64bit system. ARM-type processors are not supported.

## The Script

```bash
echo " " &&
echo "This script will attempt to install Linux Kernel 6.6.135 on this machine." &&
echo "Typically, your current version will be kept, and you will be able to ustilise it again later if Kernel 6.6 does not work." &&
echo " " &&
read -p "Press Enter to continue, or abort by pressing CTRL+C" nothing &&
echo " " &&
echo "Downloading Kernel 6.6.135 Packages" &&
echo "4 Files, ~194 MB to Download" &&
echo " " &&
echo "Creating Kernel Directory in Home folder" &&
echo " " &&
mkdir -p $HOME/howtoubuntu-kernel-6-6-135 &&
cd $HOME/howtoubuntu-kernel-6-6-135 &&
echo " " &&
echo "Downloading File 1 of 4, 13 MB" &&
echo " " &&
wget https://kernel.ubuntu.com/mainline/v6.6.135/amd64/linux-headers-6.6.135-0606135_6.6.135-0606135.202604180945_all.deb &&
echo " " &&
echo "Downloading File 2 of 4, 3.2 MB" &&
echo " " &&
wget https://kernel.ubuntu.com/mainline/v6.6.135/amd64/linux-headers-6.6.135-0606135-generic_6.6.135-0606135.202604180945_amd64.deb &&
echo " " &&
echo "Downloading File 3 of 4, 14 MB" &&
wget https://kernel.ubuntu.com/mainline/v6.6.135/amd64/linux-image-unsigned-6.6.135-0606135-generic_6.6.135-0606135.202604180945_amd64.deb &&
echo " " &&
echo "Downloading File 4 of 4, 164 MB" &&
wget https://kernel.ubuntu.com/mainline/v6.6.135/amd64/linux-modules-6.6.135-0606135-generic_6.6.135-0606135.202604180945_amd64.deb &&
echo " " &&
echo "Installing Kernel" &&
echo "This step will require you password." &&
echo "This is the last step you can safely cancel at." &&
echo "Use Ctrl+C to cancel." &&
echo " " &&
sudo dpkg -i *.deb &&
echo " " &&
echo "Installation Complete" &&
echo " " &&
read -p "Press Enter to Delete the Downloads, or CTRL+C to keep them." nothing &&
echo " " &&
sudo rm -rf $HOME/howtoubuntu-kernel-6-6-135
```
