Finally, it should be noted that this script will NOT automatically determine your system architecture, utilising only the amd64 packages for a 64bit system. ARM-type processors are not supported.

## The Script

```bash
echo " " &&
echo "This script will attempt to install Linux Kernel 6.12.82 on this machine." &&
echo "Typically, your current version will be kept, and you will be able to ustilise it again later if Kernel 6.12 does not work." &&
echo " " &&
read -p "Press Enter to continue, or abort by pressing CTRL+C" nothing &&
echo " " &&
echo "Downloading Kernel 6.12.82 Packages" &&
echo "4 Files, ~208 MB to Download" &&
echo " " &&
echo "Creating Kernel Directory in Home folder" &&
echo " " &&
mkdir -p $HOME/howtoubuntu-kernel-6-12-82 &&
cd $HOME/howtoubuntu-kernel-6-12-82 &&
echo " " &&
echo "Downloading File 1 of 4, 13 MB" &&
echo " " &&
wget https://kernel.ubuntu.com/mainline/v6.12.82/amd64/linux-headers-6.12.82-061282_6.12.82-061282.202604181050_all.deb &&
echo " " &&
echo "Downloading File 2 of 4, 3.5 MB" &&
echo " " &&
wget https://kernel.ubuntu.com/mainline/v6.12.82/amd64/linux-headers-6.12.82-061282-generic_6.12.82-061282.202604181050_amd64.deb &&
echo " " &&
echo "Downloading File 3 of 4, 15 MB" &&
wget https://kernel.ubuntu.com/mainline/v6.12.82/amd64/linux-image-unsigned-6.12.82-061282-generic_6.12.82-061282.202604181050_amd64.deb &&
echo " " &&
echo "Downloading File 4 of 4, 176 MB" &&
wget https://kernel.ubuntu.com/mainline/v6.12.82/amd64/linux-modules-6.12.82-061282-generic_6.12.82-061282.202604181050_amd64.deb &&
echo " " &&
echo "Installing Kernel" &&
echo "This step will require you password." &&
echo "This is the last step you can safely cancel at." &&
echo "Use Ctrl+C to cancel." &&
echo " " &&
sudo dpkg -i *.deb &&
echo " " &&
echo "Installation Complete" &&
echo " " &&
read -p "Press Enter to Delete the Downloads, or CTRL+C to keep them." nothing &&
echo " " &&
sudo rm -rf $HOME/howtoubuntu-kernel-6-12-82
```
