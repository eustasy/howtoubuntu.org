## Recommended System Requirements

> **Note:** These are recommendations only. Ubuntu 26.04 raised its recommended RAM target this year to better reflect modern multitasking, with the previous bump in 2019. Ubuntu 26.04 can still run on less, but performance may be impacted.

**Ubuntu 26.04 LTS (Resolute Raccoon) Recommended Requirements:**

- **Processor:** 2 GHz dual-core (64-bit)
- **Memory:** 6 GB RAM
- **Storage:** 25 GB free hard drive space

Earlier releases had lower requirements, but the above is recommended for a comfortable experience. Ubuntu flavours like Lubuntu may work better on older or low-memory hardware.

## New Features in Ubuntu 26.04

### Wayland by default
Ubuntu now uses Wayland instead of X11/Xorg for the desktop session, with smoother display handling and modern graphics support.

### Seven new default apps
Ubuntu 26.04 introduces seven new default applications in the desktop install, including:

- **Papers** – replaces Evince as the default document viewer with ink annotation and signature support.
- **Loupe** – the new GTK4 image viewer that replaces Eye of GNOME.
- **Ptyxis** – the new default terminal with GPU-accelerated rendering.
- **Resources** – replaces System Monitor with a modern process, service and hardware overview.
- **Showtime** – replaces Totem as the default video player on extended installs.
- **Security Center** – provides a central hub for security and Ubuntu Pro settings.
- **Sysprof** – developer-focused performance profiling and debugging tool.

### App Center supports Deb packages
App Center can now manage Debian (.deb) software directly, making it easier to install and update traditional packages.

### HDR, VRR and smarter scaling
Ubuntu 26.04 adds HDR, variable refresh rate support, and smarter display scaling for better visuals on modern screens.

### Software & Updates removed
The legacy Software & Updates app has been dropped in favor of newer settings-based tools.

### Startup Applications moved
Startup Applications has been moved into the main system settings area for easier access and management.

### Linux 7.0 and Mesa 26.0.x
This release includes Linux kernel 7.0 and Mesa 26.0.x for more recent hardware support and improved graphics performance.
